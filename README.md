\# 基于 RAGFlow 的 MaxKB 产品文档智能问答系统



\## 1. 项目背景



MaxKB 官方文档涵盖安装部署、模型配置、知识库管理、智能体配置、

工作流以及常见问题等内容。随着文档数量增加，用户依靠目录和关键词

查找解决方案的效率较低。



本项目使用 MaxKB 官方产品文档作为实验数据，基于 RAGFlow 构建产品

技术支持智能问答系统，并围绕文档清洗、文档切片、混合检索、

Reranker 重排序、引用溯源和离线评测开展优化。



\## 2. 项目目标



1\. 建立 MaxKB 产品文档知识库；

2\. 支持安装、模型、知识库、智能体等问题的自然语言查询；

3\. 对比向量检索、全文检索和混合检索；

4\. 使用 Reranker 优化候选文档排序；

5\. 建立固定测试集并量化优化效果；

6\. 通过 API 开发独立问答页面。



\## 3. 技术栈



\- RAGFlow

\- Docker

\- Python

\- LangChain

\- Streamlit

\- Embedding Model

\- Reranker Model

\- Large Language Model



\## 4. 数据来源



数据来自 MaxKB 官方 v2 产品文档。



主要模块：



\- 快速入门

\- 模型管理

\- 知识库管理

\- 智能体配置

\- 工作流

\- 安装部署常见问题

\- 知识库常见问题



完整原始数据仅用于本地实验，公共仓库主要保留数据来源、处理脚本、

清洗规则和评测结果。
